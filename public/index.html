How branch attribution works

Billing APIs only report spend per key and day. The branch view comes from your own machine instead:

  • Claude Code logs every model call with its time and tokens.
  • Your repository's reflog records which branch was checked out at each moment.

codespend-branches joins the two. It prices the tokens at list price and sends per-day, per-branch totals here. It never sends prompts, code or file paths. Run it in a repository:

cd ~/src/your-repo
node /path/to/codespend/bin/codespend-branches.mjs            # posts to http://127.0.0.1:3000
node /path/to/codespend/bin/codespend-branches.mjs --dry-run  # print only

Run it again any time; it replaces its earlier report. Branch costs are estimates and are not added to budgets.

Project budget and alerts

Alerts go to email and Slack at 50%, 80% and 100% of a project's monthly budget, once per threshold each month. Keys and webhooks are encrypted on this server and never shown again. "Remove" deletes a key and its synced usage.
