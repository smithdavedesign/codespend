# CodeSpend — budget alerts and spend visibility for coding agents

For developers and teams using AI coding agents, it tracks usage across Claude, Cursor, Copilot, and OpenAI APIs, provides per-project budgets with alerts, and attributes cost to tasks and branches to prevent surprise bills.
